# Trafik Lambasına Şiir Okuyan Güvercin

> **UYARI:** Bu belge, 13 Eylül 2026 tarihinde Gökyüzü İşleri Genel Müdürlüğü tarafından *neredeyse* onaylanmıştır. Onay mühürü kaybolmuştur. Mühürü gören güvercin lütfen iade etsin.

## Bu nedir?

Bu yazılım, şehirdeki trafik lambalarının yalnızlık krizini çözmek için tasarlanmış **ciddi bir kamu hizmetidir**.  
Lambalar gün boyu kırmızı-sarı-yeşil diye bağırır, kimse onlara şiir okumaz. Bu durum kabul edilemezdir.

Yazılım çalıştığında:

1. Rastgele bir lamba rengi seçer.
2. O renge uygun (ama aslında hiç uygun olmayan) bir şiir okur.
3. Şiiri gökyüzüne gönderildiğini iddia eder.
4. Başarı oranı bilimsel olarak %0 ile %100 arasındadır. Ölçüm yapılmadı.

## Kurulum

```bash
python3 guvercin.py
```

Başka bir şey gerekmez. Güvercin kendi yemini kendisi bulur.
